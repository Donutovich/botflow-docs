Четыре экрана в настройках компании, группа «Трекер». Они задают правила, по которым трекер принимает
постбеки и считает показатели, поэтому загляните сюда до запуска первых кампаний.

<Info>
  Раздел доступен владельцу и администратору компании с включённым правом «Трекер». Про права
  смотрите [Настройки](/ru/settings).
</Info>

## Типы конверсий

Список событий, по которым принимаются постбеки и считается воронка. Каждый тип это строка с ключом,
названием, свойствами и списком разрешённых переходов.

| Поле | Что задаёт |
| --- | --- |
| **Ключ** | Латиница строчными, цифры и подчёркивания. Используется в постбек-ссылке, поэтому менять его после настройки партнёрки не стоит. |
| **Название** | Как событие называется в отчётах и на дашборде. |
| **Разрешённые переходы** | Какие события могут идти после этого. |

Правила переходов решают, какой постбек будет принят. Например, если после депозита разрешена только
регистрация, повторная регистрация после депозита будет отклонена как ошибка партнёрки, и в журнале
конверсий вы увидите результат `rejected_transition`.

<Warning>
  Событие, которое повторяется (RD, повторный депозит), должно разрешать переход на само себя. Без
  этого второй такой постбек будет отклонён.
</Warning>

Тип без переходов помечен как `terminal (нет переходов)`: после него не принимается ничего. Системные
типы отмечены значком «системный», их набор меняется только добавлением своих типов рядом.

## Кастомные метрики

Формулы для производных показателей на дашборде и в отчётах. Шесть метрик доступны по умолчанию, свои
добавляются кнопкой «Добавить метрику».

| Поле | Что задаёт |
| --- | --- |
| **Имя** | Название метрики в списке и на дашборде. |
| **Ключ** | Латинские буквы, цифры и подчёркивание. |
| **Формула** | Выражение из базовых показателей. |
| **Формат** | «Число», «Валюта ($)» или «Процент (%)». |

В формуле доступны клики, уникальные клики, просмотры лендинга, подписки, контакты, регистрации, FTD,
RD, суммы депозитов и расход. Метрика, отмеченная плашкой «На дашборде», появляется в списке «Настроить
метрики» на дашборде трекера.

<Tip>
  Формат влияет только на отображение. Процент удобен для конверсий вида «регистрации к кликам»,
  валюта для средних сумм.
</Tip>

## Авто-правила

Автоматические действия при заданных условиях: например поставить кампанию на паузу, когда трафик
идёт, а конверсий нет. Условия проверяются каждые 5 минут.

| Поле | Что задаёт |
| --- | --- |
| **Имя** | Как правило называется в списке. |
| **Условие** | Что отслеживаем. |
| **Действие** | Что делаем при срабатывании. |
| **Cooldown (мин)** | Сколько минут правило молчит после срабатывания, чтобы не сработать повторно на той же ситуации. |

Условия:

| Условие | Когда срабатывает |
| --- | --- |
| **Постбеки без совпадения клика** | Доля постбеков, у которых не нашёлся `click_id`, превысила порог за окно. Задаются «Окно, минут» и «Порог, %». |
| **Трафик идёт, а событий нет** | За окно были клики, но не было событий выбранного типа. Задаются «Тип события» и «Окно, минут». |
| **Лимит конверсий достигнут** | Число конверсий дошло до заданного «Лимита». |

Действия:

| Действие | Что делает |
| --- | --- |
| **Уведомление в Telegram** | Присылает сообщение в указанный «Chat ID (Telegram)». |
| **Поставить кампанию на паузу** | Останавливает кампанию, трафик по ссылке перестаёт учитываться. |
| **Переключить домен кампании** | Переводит кампанию на выбранный «Новый домен». |

Поле «Только для кампании» необязательное. Если его не заполнять, правило смотрит на все кампании
компании. Если выбрать кампанию, правило считает условие только по ней.

<Warning>
  Правило без выбранной кампании считает условие по всей компании целиком. Для правил, которые ставят
  кампанию на паузу, почти всегда нужно выбрать конкретную кампанию: иначе трафик одной кампании
  повлияет на решение по другой.
</Warning>

В списке правил видны колонки «Имя», «Условие», «Действие», «Cooldown», «Последний срабат.» и
«Активно». Правило можно изменить, отключить переключателем или удалить.

## Чёрные и белые списки

Списки значений (`fb_adset_id`, `sub1`, `country` и других) для выгрузки в Facebook Audience. Экспорт
идёт в CSV, готовый к загрузке в Audience Manager.

| Поле | Что задаёт |
| --- | --- |
| **Тип** | «Чёрный (exclude)» или «Белый (include)». |
| **Поле** | По какому значению отбираем: `fb_adset_id`, `sub1`, `country` и так далее. |
| **Значение** | Само значение, которое попадает в список. |
| **Комментарий** | Необязательная пометка для команды, например «Bad creative». |

Записи группируются по паре типа и поля, поэтому один экран держит сразу несколько списков: скажем,
чёрный по адсетам и белый по странам.
