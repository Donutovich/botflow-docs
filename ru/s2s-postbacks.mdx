S2S-постбек используется для отправки информации во внешний сервис. Например, события о конверсиях:
регистрация, первый депозит, повторный депозит. BotFlow отправляет запрос на ваш URL в момент события,
подставляя значения в макросы.

Не путайте с разделом [Постбеки](/ru/postbacks): там платформа **принимает** события от партнёрских
сетей, а здесь **отправляет** их дальше, например в трекер источника трафика или в вашу CRM.

## Как добавить постбек

1. Откройте «Трекер» и перейдите на вкладку «S2S-постбеки».
2. Нажмите «Добавить».
3. Заполните поля:

| Поле | Описание |
|---|---|
| Название | Как постбек будет называться в списке и логе. |
| URL | Адрес внешнего сервиса. Внутри URL можно использовать макросы, они подставятся при отправке. |
| Метод отправки | GET или POST. При POST параметры из URL уходят в теле запроса. |
| События | При каких событиях отправлять постбек. Список совпадает с типами конверсий компании. |
| Кампания | Конкретная кампания, включая органические, либо «Глобальный» для всех кампаний сразу. |

<Info>
  Вариант «Глобальный» доступен владельцу и администраторам компании. Байер настраивает постбеки на
  своих кампаниях.
</Info>

## Встроенные макросы

| Макрос | Описание |
|---|---|
| `{{click_id}}` | Идентификатор клика, по которому связаны регистрация и депозит. |
| `{{event_type}}` | Тип события: registration, sale, resale и другие. |
| `{{status}}` | Статус события, если партнёрка его передала. |
| `{{payout}}` | Сумма события. |
| `{{currency}}` | Валюта суммы. |
| `{{tid}}` | Идентификатор транзакции на стороне партнёрки. |
| `{{sub1}}` … `{{sub5}}` | Sub-параметры клика. |
| `{{campaign_id}}` | Идентификатор кампании события. |
| `{{bot_id}}` | Идентификатор бота события. |

Кроме встроенных макросов подставляются переменные бота: `{{tag}}` и любые ваши переменные.
Неизвестный макрос остаётся в URL как есть, а известный без значения заменяется на пустую строку.

Пример URL:

```text
https://tracker.example.com/postback?cid={{click_id}}&status={{event_type}}&payout={{payout}}
```

## Лог отправок

Вкладка «Лог» показывает каждую отправку: время, постбек, статус, HTTP-код ответа и итоговый URL.

| Статус | Что значит |
|---|---|
| Доставлено | Получатель ответил кодом 2xx или 3xx. |
| Ошибка | Получатель ответил кодом 4xx или 5xx. Проверьте формат URL на стороне получателя. Ошибка без кода ответа означает, что адрес постбека указан неверно: проверьте поле URL в настройках. |
| Ошибка сети | Соединение не установилось. Платформа повторит отправку автоматически. |
| Исход неизвестен | Ответ получателя не удалось прочитать. Повторной отправки не будет. |

Каждое событие отправляется один раз: если получатель ответил, повторной отправки не будет. Дубликаты
конверсий на стороне получателя поэтому не появляются.

## Как проверить настройку

Совершите конверсию и проверьте вкладку «Лог». Быстрый способ без реального трафика: в разделе
[Постбеки](/ru/postbacks) нажмите «Тест» у любой интеграции. Тестовое событие уйдёт по всем включённым S2S-постбекам
и появится в логе с пометкой «Тест».

<Warning>
  Тестовая отправка уходит на реальный URL из настроек постбека. Получатель увидит тестовое событие.
</Warning>
