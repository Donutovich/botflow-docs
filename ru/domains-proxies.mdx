Домены и прокси нужны кампаниям с источником **Facebook Ads**. Домен обслуживает трекинговые ссылки и
лендинги, а прокси доставляет события конверсий в Facebook. Кампаниям с источником Telegram или
инвайт-ссылкой они не требуются.

Оба раздела живут в разделе «Трекер» и доступны администратору, владельцу и участникам с доступом к
трекеру. В горизонтальном меню трекера это вкладки «Домены» и «Прокси».

## Домены

Свои домены нужны для трекинговых ссылок, редиректов и лендингов. Без подключённого домена трекинговые
ссылки Facebook-кампаний не работают: ссылка в объявлении идёт через ваш домен, ведёт на лендинг и дальше
в бота.

Каждый домен подключается в одном из двух режимов. Выбор режима зависит от того, где вы держите DNS и
кто выпускает SSL-сертификат.

<Columns cols={2}>
  <Card title="Manual (CNAME)" icon="wrench">
    Вы сами создаёте CNAME-запись у своего DNS-провайдера. SSL терминируется на вашей стороне. BotFlow
    проверяет запись и активирует домен.
  </Card>
  <Card title="CF API" icon="cloud">
    BotFlow создаёт зону и DNS-запись через ваш Cloudflare API token. Сертификат Cloudflare выпустит
    автоматически. Токен подключается один раз в разделе «Настройки → Интеграции».
  </Card>
</Columns>

### Как подключить домен

<Steps>
  <Step title="Добавьте домен" icon="globe">
    Нажмите «Добавить домен», введите корневой домен (например, `example.com`) или поддомен
    (`track.example.com`) и выберите режим. Режим CF API доступен, только когда подключён Cloudflare
    API token.
  </Step>
  <Step title="Пропишите DNS" icon="server">
    В режиме **Manual** разверните строку домена: панель покажет точную CNAME-запись с полями Source,
    Type и Target. Создайте её у своего DNS-провайдера. В режиме **CF API** BotFlow пропишет запись
    сам; для новой зоны панель подскажет NS-серверы, которые нужно указать у регистратора домена.
  </Step>
  <Step title="Проверьте статус" icon="circle-check">
    Нажмите «Проверить статус». Домен станет активным, когда DNS распространится. CNAME обычно
    распространяется за 5-15 минут, смена NS-серверов у регистратора может занимать от нескольких минут
    до суток.
  </Step>
</Steps>

### Статусы домена

У каждого домена есть один из трёх статусов.

| Статус | Что означает |
|---|---|
| **Активен** | DNS настроен верно, домен готов обслуживать трекинговые ссылки. |
| **Ожидание** | Запись пока не найдена или ещё распространяется. Для доменов на CF API мы перепроверяем NS каждые 10 минут; для Manual нажмите «Проверить статус» после создания CNAME. |
| **Ошибка** | Проверка не прошла. Разверните строку, чтобы увидеть текст ошибки и подсказку по настройке. |

<Info>
  Поддомены группируются под своим корневым доменом. Разверните строку корня, чтобы увидеть поддомены,
  их статусы и инструкции по DNS.
</Info>

<Warning>
  Домен нельзя отвязать, пока он используется в кампании или пока у него есть подключённые поддомены.
  Сначала переключите кампанию на другой домен или удалите поддомены. После отвязки удалите CNAME-запись
  в своём DNS вручную.
</Warning>

## Cloudflare API token

Режим CF API создаёт зоны и DNS-записи в вашем аккаунте Cloudflare автоматически, чтобы вы не прописывали
каждую запись руками. Для этого один раз подключите API-токен с ограниченными правами в разделе
«Настройки → Интеграции».

<Steps>
  <Step title="Создайте токен" icon="key">
    Откройте `dash.cloudflare.com/profile/api-tokens`, нажмите **Create Token** и выберите **Custom
    token**.
  </Step>
  <Step title="Выдайте права" icon="shield-check">
    Токену нужны разрешения на управление зонами и DNS:
    <br />• `Zone` / `Zone` / `Read`
    <br />• `Zone` / `Zone` / `Edit`
    <br />• `Zone` / `DNS` / `Edit`
    <br />В Account Resources выберите `Include / All accounts`, в Zone Resources `Include / All zones`.
  </Step>
  <Step title="Вставьте токен" icon="link">
    Скопируйте токен и вставьте его в поле на странице интеграции. Нажмите «Подключить». Токен хранится
    в зашифрованном виде и используется только для управления вашими доменами.
  </Step>
</Steps>

После подключения на странице видны статус токена и время последней проверки. Кнопка «Проверить
подключение» перепроверяет токен, «Отключить» убирает интеграцию.

| Статус токена | Что означает |
|---|---|
| **Активен** | Токен валиден, домены в режиме CF API управляются автоматически. |
| **Недействителен** | Токен не проходит проверку. Проверьте права и создайте новый. |
| **Token отозван** | Токен отозван на стороне Cloudflare. Подключите новый. |

<Note>
  На компанию подключается один Cloudflare API token. Если его отключить, уже созданные домены в режиме
  CF API перестанут управляться через API, но останутся в вашем аккаунте Cloudflare.
</Note>

## Прокси

Facebook Conversions API (CAPI) блокирует и ограничивает запросы, приходящие напрямую с
дата-центровых IP. Чтобы события конверсий доходили до Facebook, платформа отправляет их через ваш
прокси. Прокси нужен только кампаниям с источником Facebook Ads.

### Как добавить прокси

Нажмите «Добавить» и заполните поля.

<Columns cols={2}>
  <Card title="Название" icon="tag">
    Понятное имя, по которому вы узнаете прокси в списке. Например, `DE residential #1`.
  </Card>
  <Card title="Тип" icon="network-wired">
    `HTTP / HTTPS` или `SOCKS5`.
  </Card>
  <Card title="Хост и порт" icon="server">
    Адрес прокси и порт от 1 до 65535.
  </Card>
  <Card title="Login и пароль" icon="lock">
    Необязательны. Заполните, если прокси требует авторизацию.
  </Card>
</Columns>

### Проверка прокси

Кнопка проверки в строке прокси отправляет тестовый запрос и показывает результат. По нему видно, что
прокси жив, ещё до запуска кампании.

| Статус | Что означает |
|---|---|
| **OK** | Прокси ответил, показывается задержка в миллисекундах. |
| **Timeout** | Прокси не ответил вовремя. |
| **Не работает** | Прокси вернул ошибку или недоступен. Текст ошибки виден в строке. |
| **Не проверен** | Проверка ещё не запускалась. |

<Tip>
  Один прокси можно переиспользовать в нескольких Facebook-кампаниях. Прокси выбирается на шаге
  «Трекинг» при создании кампании, рядом с доменом и FB Pixel. Подробнее о кампаниях смотрите в разделе
  [Трекер и кампании](/ru/tracker).
</Tip>

<Info>
  Отключённый прокси помечается в списке и не используется для отправки. Список фильтруется по статусу и
  ищется по названию или хосту.
</Info>
