Два журнала отвечают на разные вопросы. «Журнал событий» показывает, что происходило с ботами, а
«Журнал действий» в настройках компании показывает, кто менял саму компанию.

## Журнал событий

Раздел «Логи» в меню. Лента событий по ботам с фильтрами по боту, типу события и поиском по описанию.
Список листается кнопками «Назад» и «Вперёд», события за сегодня помечены временем. Поиск по
описанию работает по открытой странице, а не по всему журналу, поэтому сначала выберите бота и тип
события. Рядом есть кнопка выгрузки в CSV.

| Событие | Когда появляется |
| --- | --- |
| **Сценарий создан** | В конструкторе появился новый сценарий. |
| **Сценарий обновлён** | Схему сценария изменили. |
| **Сценарий удалён** | Сценарий убрали из конструктора. |
| **Бот подключён** | Бот добавлен в воркспейс. |
| **Бот выключен** | Бота остановили переключателем. |
| **Блокировка подписчика** | Подписчика заблокировали из карточки или переписки. |
| **Подписчик удалён** | Подписчика удалили. |
| **Очистка подписчиков** | Прошло массовое удаление подписчиков. |

В журнале есть и другие события, в том числе по доступам и ключам. Таблица выше перечисляет те,
которые вы увидите чаще всего.

Если вашей роли данные подписчиков показываются скрытыми, у части записей вместо описания вы
увидите пометку, что запись содержит данные подписчика. Сама запись остаётся на месте: видно, что
действие было, кто его совершил и когда. Чтобы увидеть данные подписчика, запросите доступ в разделе
«Запросы на раскрытие».

<Tip>
  Когда воронка повела себя не так, как вы ожидали, начните отсюда: по времени события видно, какая
  правка сценария это вызвала.
</Tip>

## Журнал действий компании

Настройки компании, группа «Команда», пункт «Журнал действий». Здесь собраны изменения самой компании:
создание и удаление воркспейсов, смена ролей, блокировки, передача владения.

| Колонка | Что показывает |
| --- | --- |
| **Время** | Когда произошло. |
| **Автор** | Кто это сделал. Действия платформы помечены как «Система». |
| **Действие** | Тип изменения. |
| **Описание** | Подробности изменения. |
| **Контекст** | К чему относится изменение. |

Фильтр «Все типы» сужает список до нужного типа действия.

<Info>
  Журнал действий видят владелец и администратор компании. Журнал событий по ботам доступен участникам
  с доступом к этим ботам.
</Info>
