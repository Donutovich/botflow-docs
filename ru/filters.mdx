Фильтр это набор условий, которым должен отвечать подписчик, чтобы попасть в выборку. С его помощью вы сужаете список чатов до нужных людей: «те, кто зарегистрировался, но не внёс депозит», «депозиты от 10 долларов», «подписчики из RU без тегов» и так далее.

Отдельного пункта меню «Фильтры» нет. Они живут внутри других разделов и везде собираются одним и тем же конструктором условий.

Собранное условие можно **сохранить под именем**. Один раз собрав условие и дав ему имя, вы переиспользуете его в [рассылках](/ru/broadcasts) как аудиторию и в блоке «Условие» [конструктора](/ru/constructor) как ветку развилки, не пересобирая заново.

## Быстрые фильтры списка чатов

В разделе [Мессенджер](/ru/messenger) над списком чатов есть готовые фильтры, которые не нужно настраивать. Кнопка с иконкой ползунков справа от поиска открывает меню из пяти режимов. Активен всегда один.

| Режим | Что показывает |
| --- | --- |
| Все чаты | все диалоги бота |
| Непрочитанные | диалоги с непрочитанными входящими |
| ИИ | диалоги, которые сейчас ведёт [ИИ-оператор](/ru/ai-operator) |
| Оператор | диалоги, переведённые на ручной режим |
| Заблокированные | подписчики, заблокировавшие бота |

### Быстрые фильтры воронки

Над списком идёт полоса быстрых фильтров по воронке продаж. Их названия одинаковы во всех языках интерфейса.

- `All`: все чаты.
- `Reg`: есть событие регистрации.
- `FD`: был первый депозит.
- `RD`: был повторный депозит.
- `Deposits`: сумма депозитов больше нуля.
- `<$5`, `$5–10`, `$10–100`, `>$100`: срезы по сумме депозитов.

В той же полосе показываются сохранённые фильтры этого бота, а кнопка «Фильтр» в конце ряда открывает конструктор условий. Режим списка складывается с остальным отбором, а быстрый фильтр, сохранённый и свой сменяют друг друга.

## Конструктор условий

Кнопка «Фильтр» (в «Сообщениях») или «Добавить фильтр» (в «Подписчиках») открывает панель «Фильтр подписчиков». Здесь вы собираете условие из отдельных строк.

Каждая строка это три части:

1. **Поле**: по чему фильтруем (страна, сумма депозитов, теги и так далее).
2. **Оператор**: как сравниваем (равно, больше, содержит, за последние N дней).
3. **Значение**: с чем сравниваем. Для некоторых операторов («пусто», «не пусто») значение не нужно.

<Steps>
  <Step title="Добавьте первое условие" icon="plus">
    Нажмите «Добавить условие», выберите поле из списка, затем оператор и укажите значение.
  </Step>
  <Step title="Добавьте ещё условия в группу" icon="layer-group">
    Условия внутри одной группы соединяются переключателем «И» / «ИЛИ». «И» требует выполнения всех условий сразу, «ИЛИ» достаточно любого одного.
  </Step>
  <Step title="Добавьте вторую группу" icon="code-branch">
    Правило вида «(A и B) или C» собирается двумя группами: в первой A и B через «И», во второй C. Группы между собой всегда объединяются через «ИЛИ».
  </Step>
  <Step title="Примените" icon="check">
    Нажмите «Применить». Список чатов или таблица подписчиков перестроятся под ваше условие.
  </Step>
  <Step title="Проверьте счётчик" icon="calculator">
    Рядом с применённым фильтром показывается, сколько подписчиков подходит: «N подписчиков» или «N / T», где T это все подписчики бота.
  </Step>
</Steps>

<Note>В одном фильтре можно собрать до 50 условий.</Note>

### Какие поля доступны

Поля сгруппированы в выпадающем списке. Названия групп английские, сами поля подписаны по-русски.
По-английски остаются только те, у которых нет общепринятого русского названия: `Telegram ID`,
`Username`, `sub1`-`sub5`, `UTM source` и поля Facebook.

| Группа | Поля |
| --- | --- |
| Subscriber | Telegram ID, Username, Имя, Фамилия, Страна, Start-параметр, Язык Telegram, Дата рождения, Есть аватар, Дата подписки, Заблокирован ботом, Дата блокировки, Заблокирован админом, Дата блокировки админом, [Теги](/ru/tags) |
| Deposits | Есть регистрация, Дата регистрации, Был FTD, Дата первого FTD, Дата последнего FTD, Повторный депозит, Сумма депозитов, Сумма FTD, Сумма повторных депозитов, Кол-во депозитов, Кол-во конверсий, Был вывод |
| Saved filters | Сохранённый фильтр как условие |
| Traffic | Страна клика, Город, Регион, Язык клика, Устройство, Тип источника, Кампания, UTM source, FB campaign, FB adset, FB ad, FB campaign name, FB adset name, Прокси/VPN, Тип прокси, sub1-sub5 |
| Dialog | Последнее сообщение, Направление сообщения, Непрочитанные, Ждёт ответа |
| Funnel | Блок воронки |
| Activity | Последняя активность |
| Variables | Ваши [переменные бота](/ru/variables) со значением на подписчика, в списке они подписаны своим именем |

<Info>События воронки (регистрация, FTD, RD) приходят из [трекера](/ru/tracker) и уже готовы к использованию в группе Deposits как отдельные условия. Отдельно считать их не нужно.</Info>

### Операторы

Набор операторов зависит от типа поля.

| Тип поля | Операторы |
| --- | --- |
| Текст («Имя», `sub1`, переменные) | равно, не равно, содержит, не содержит, начинается с, заканчивается на, любой из, ни один из, пусто, не пусто |
| Число («Сумма депозитов», «Сумма FTD», «Кол-во депозитов») | равно, не равно, больше, больше или равно, меньше, меньше или равно, между |
| Дата («Дата подписки», «Дата первого FTD») | больше или равно, меньше или равно, между, за последние, пусто, не пусто |
| Да / Нет («Был FTD», «Заблокирован ботом») | равно |
| Список значений («Страна», «Устройство», «Сохранённый фильтр») | любой из, ни один из, равно, не равно, пусто, не пусто |
| [Теги](/ru/tags) | имеет любой из, имеет все из, не имеет ни одного из, имеет только эти, без тегов, есть теги |

<Tip>Оператор «любой из» удобен, когда значений несколько: введите `RU, US, KZ`, нажимая Enter после каждого, и в выборку попадут подписчики из любой из этих стран.</Tip>

## Сохранение фильтра

Собранное условие можно сохранить под именем и переиспользовать. В панели фильтра нажмите «Сохранить как…», введите название в поле «Название фильтра» (например, `VIP с FTD`) и нажмите «Сохранить». Для уже сохранённого фильтра рядом появляется «Обновить сохранённый».

Что важно знать о сохранённых фильтрах:

- Фильтр принадлежит **боту** и виден всей команде, у которой есть доступ к этому боту.
- Создавать, переименовывать и удалять фильтры может оператор и роли выше.
- Избранные фильтры помечаются звёздочкой и всплывают в начало полосы папок. Избранное общее для всей команды.
- На одного бота можно хранить до 50 фильтров.

<Warning>Удаление фильтра необратимо. Переписки и подписчики при этом остаются на месте, удаляется только сам сохранённый набор условий. Рассылки, которые уже стартовали с этим фильтром, свою аудиторию сохраняют: она замораживается в момент запуска. А вот ветки блока «Условие» в [конструкторе](/ru/constructor), построенные на удалённом фильтре, перестанут находить кого-либо, и подписчики пойдут по ветке по умолчанию. Проверьте воронки, прежде чем удалять фильтр.</Warning>

## Переиспользование фильтров

Сохранённый фильтр выбирается как аудитория в [рассылках](/ru/broadcasts): на шаге выбора аудитории укажите сохранённый фильтр или соберите новый прямо в мастере тем же конструктором.

Внутри воронки те же условия работают в блоке «Условие» [конструктора](/ru/constructor): он проверяет ветки сверху вниз и сразу уводит подписчика по первой подходящей, например тех, у кого есть депозит, на личное предложение, а остальных в общее меню.
