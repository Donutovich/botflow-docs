Приглашайте клиентов по своим ссылкам и получайте комиссию с их потребления. Раздел «Реферальная
программа» открывается из меню профиля, доступен любому аккаунту и состоит из вкладок **Ссылки**,
**Рефералы** и **Выплаты**.

## Как это работает

<Steps>
  <Step title="Создайте ссылку и поделитесь ею" icon="link">
    У каждого аккаунта есть основная ссылка, и вы можете создать дополнительные, по одной на каждый канал.
    Ссылка ведёт на регистрацию, и приглашённые по ней компании попадают в ваш список рефералов.
  </Step>
  <Step title="Приглашённый пользуется платформой" icon="users">
    Когда компания приглашённого тратит баланс на работу ботов и сообщения, вам начисляется комиссия с
    этого потребления.
  </Step>
  <Step title="Выводите накопленное" icon="wallet">
    Комиссия копится на балансе программы. Когда сумма достигнет минимума, запросите выплату в USDT-TRC20.
  </Step>
</Steps>

## Раздел «Ссылки»

Вверху раздела показаны ваша основная реферальная ссылка с кнопкой «Копировать» и ставка комиссии. Ниже идут карточки
показателей за всё время и график начислений за 30 дней.

<Columns cols={2}>
  <Card title="Рефералы" icon="user-group">
    Сколько компаний зарегистрировалось по вашим ссылкам.
  </Card>
  <Card title="К выплате" icon="coins">
    Накопленная комиссия, доступная к выводу.
  </Card>
  <Card title="В обработке" icon="clock">
    Сумма по заявкам на вывод, которые ещё исполняются.
  </Card>
  <Card title="Выплачено" icon="circle-check">
    Сколько уже выплачено вам за всё время.
  </Card>
</Columns>

Потребление приглашённых компаний показано отдельно по каждому рефералу в разделе «Рефералы».

Ниже обзора идёт управление ссылками. По каждой ссылке в таблице видно: название, сам код ссылки с кнопкой копирования, оффер и лендинг, а также статистику за
период: клики, регистрации, конверсии и комиссию. Конверсии это сколько приглашённых по ссылке пополнили
баланс. Основную ссылку удалить нельзя.

### Создание ссылки

Кнопка «Создать ссылку» открывает форму:

<Steps>
  <Step title="Название" icon="pen">
    Понятное вам название канала, например «Telegram-канал». Оно видно только вам и помогает различать
    ссылки в статистике.
  </Step>
  <Step title="Оффер" icon="gift">
    Оффер это предложение для приглашённого. По умолчанию действует основной оффер платформы. Оффер
    **закрепляется за ссылкой и не меняется после создания**: чтобы использовать другой оффер, создайте
    новую ссылку.
  </Step>
  <Step title="Лендинг" icon="browser">
    Страница, на которую попадёт приглашённый. По умолчанию это главная страница.
  </Step>
</Steps>

Готовую ссылку можно скопировать кнопкой копирования в строке или в меню «⋯». В том же меню есть «Изменить»
(название и лендинг) и «Архивировать». Основную ссылку архивировать нельзя.

## Комиссия

Ставка комиссии по умолчанию **10%** и указана над карточками показателей.

Комиссия считается от **потребления** приглашённых компаний: платы за работу ботов и за сообщения.
Расходы на ответы ИИ-оператора в базу для комиссии **не входят**. Накопленная сумма показана над
карточками показателей, разбивка по каждому приглашённому на вкладке «Рефералы».

## Раздел «Рефералы»

Обезличенная разбивка по приглашённым: ярлык «Реферал №», дата регистрации и суммы. По каждому
рефералу видно:

| Колонка | Что показывает |
| --- | --- |
| Реферал | Обезличенный ярлык приглашённого. |
| Дата | Когда зарегистрировался. |
| Стадия | Регистрация, Активен или Конверсия. |
| Источник | Название ссылки, по которой он пришёл. |
| Оффер | Какой оффер был применён. |
| Потребление | Сколько потратил приглашённый. |
| Ваша комиссия | Сколько начислено вам с него. |

## Раздел «Выплаты»

Выплаты идут в USDT по сети TRON (TRC-20), напрямую в блокчейн.

<Steps>
  <Step title="Укажите адрес кошелька" icon="wallet">
    Поле «Адрес кошелька». Проверьте адрес: перевод уходит в сеть и вернуть его нельзя.
  </Step>
  <Step title="Укажите сумму" icon="coins">
    Поле «Сумма вывода». Над формой показан «Доступный баланс»; кнопка «Все» подставляет всю доступную
    сумму. Есть минимальная сумма к выводу, она подписана в форме.
  </Step>
  <Step title="Запросите выплату" icon="paper-plane">
    Нажмите «Вывести». Заявка проходит модерацию, после одобрения средства уходят в сеть.
  </Step>
</Steps>

Заявки на вывод собраны в таблице с датой, суммой, статусом и ссылкой на транзакцию. Пока идёт проверка и
перевод, статус обновляется сам. Ниже идёт «История»: все операции по программе, начисления комиссии со знаком
плюс и выплаты со знаком минус.

| Статус | Что значит |
| --- | --- |
| Ожидает | Заявка создана и ждёт проверки. |
| Одобрено | Заявка прошла модерацию. |
| В обработке | Выплата готовится к отправке. |
| Отправлено | Перевод ушёл в сеть, идёт набор подтверждений (виден счётчик подтверждений). |
| Выполнено | Средства зачислены, доступна ссылка на транзакцию. |
| Отклонено | Заявку отклонили, с указанием причины. |
| Ошибка | Отправка не прошла, с указанием причины. |

<Info>
  Если у вас уже есть заявка в обработке, её сумма показана отдельной подписью под формой, чтобы вы видели,
  сколько уже в пути.
</Info>
